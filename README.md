# Online Cake Shop Management System

## Overview
Online Cake Shop Management System is a web-based e-commerce application developed using ASP.NET, C#, and SQL Server. The system allows customers to browse cakes, place orders, make payments, and track order status.

## Technologies Used
- ASP.NET
- C#
- SQL Server
- JavaScript
- HTML
- CSS

## Features
- User Registration & Login
- Cake Catalog Management
- Shopping Cart
- Online Ordering
- Payment Integration
- Order Tracking
- Admin Dashboard
